# Battle Ludo V1

A mobile-first browser Ludo prototype designed for GitHub + Cloudflare Pages.

## Current version
- Classic four-player Ludo foundation
- Four themed armies
- Soldier-style pieces
- Barracks/home positions
- Dice and legal-move highlighting
- Capture mechanic
- Safe squares
- Win detection
- Simple AI for three opponents
- No backend required

## Deploy
Upload the repository contents to GitHub, then create a Cloudflare Pages project using the GitHub repository.

No build command is required.
Build output directory: `/`
